# Armature 2D hosted submission package

This package declares the deployed OAuth-protected MCP endpoint. The separate
`plugins/armature` package remains the portable local-engine distribution.

The root Agent Plugins manifest is authoritative for OpenAI listing and review
metadata. The Codex companion provides local package compatibility. No credentials,
local project grants, executable engine or lifecycle hooks are distributed.

The eight review cases are specifications and require a dedicated review account.
Before submission, verify publisher identity against the public policy, add an
actual accessible walkthrough recording, verify account access, run all cases and
resolve portal checks. Country availability is selected in the existing portal.
Do not interpret package validation as successful OAuth, review or publication.

The existing legacy portal draft supports `chatgpt-app-submission.json`; use that
import for the existing draft. This directory also supports the documented ZIP
submission workflow when available. Keep the existing plugin identity rather than
creating a duplicate directory listing.
