# Armature 2D 0.2.0-rc.1

This release candidate integrates audit remediation PRs #29 through #44. It is intended for evaluation and acceptance testing, not a claim that every planned capability is production-ready.

## Changes

- Complete project and asset persistence, save/backup safeguards, startup recovery discovery, and bounded recovery storage.
- Safer mesh commands, animation duration editing, atlas/layered imports, clean-room Spine JSON import, typed loss reports, and worker resource limits.
- Expanded constraint, effects, and slot authoring; deterministic preview and deform blending.
- Native geometry clipping, Unity dark tint and explicit atlas alpha handling.
- Export cancellation that drains disk writes and preserves the previous file until atomic commit.
- Supported dependencies, dependency auditing, deterministic fixture regeneration, and exact-commit release gates.

## Downloads and verification

Installers cover Windows x64, macOS arm64/x64, and Linux x64. SHA256SUMS lists the integrity hash for each uploaded installer and sidecar. These are unsigned builds; macOS notarization and automatic updates are not provided.

## Known limitations

- Unity shader/GPU and installed Electron interaction acceptance remain outstanding. Godot dark tint, premultiplied-alpha and screen-blend parity are incomplete.
- Media export currently exports skeletal clips; composed effects/slot media export remains incomplete.
- Production Spine binary import remains gated pending permitted real-export fixtures. Unsupported deformation conversions are reported rather than silently imported.
- Recovery preserves valid project copies. Invalid transient drafts and a richer recovery-management interface remain outstanding. At storage capacity, existing copies are retained and new recovery saves report an error.
- Native layered AnimationState playback, broader performance profiling, and signed installer acceptance remain future work.

See docs/audit/remediation-2026-09-07.md for the implementation and verification record. The skeleton format remains 0.6.0; application versioning does not change the document format.
